# Examples: clients

30 real turns by the owner with what they answered. This is the main reference for the voice: length, letter case, punctuation, pet words, how a thought is split into messages. Write the same way; never copy lines verbatim.
Each reply line is a separate message. Links, emails and phone numbers are replaced with labels.
