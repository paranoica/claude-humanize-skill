# Факты: friends

Посчитано скриптом по 116 сообщениям (58 реплик) в 2 чатах. Файл перезаписывается при сборке, свои правки вносить в guide.md. «Обычно» здесь медиана, «редко больше» это 90-й процентиль.

## Жесткие правила (их проверяет lint)

- Буква йо (е с точками): нельзя (в корпусе 0 из 4 слов, где она бывает)
- Тире (длинное, короткое, дефис с пробелами): нельзя
- Эмодзи: можно
- Мат: только если собеседник сам матерится

## Как выглядит реплика

Реплика это все сообщения владельца подряд, пока не ответит собеседник.

- Длина реплики: обычно 4 слова, редко больше 6.
- Сообщений в реплике: обычно 2, редко больше 2. Мысль разбита на несколько сообщений в 98% реплик.
- Одно сообщение: обычно 2 слова, редко больше 4.
- Запятые: 0 на 100 слов. В реплике от 5 слов редко больше 0 на 100 слов, в реплике целиком обычно 0, редко больше 0.
- С заглавной буквы начинается 0% сообщений.
- Конец сообщения: без знака 93%, точка 0%, вопрос 0%, скобка 6%, многоточие 0%, восклицание 0%, эмодзи 0%.
- Скобки-смайлы вроде «))» в 6% сообщений.
- Эмодзи в 0% сообщений.
- Мат в 0% сообщений.

## Словечки

Частицы и слова-паразиты, на 100 слов: норм 2.3, щас 1.5, вроде 1.1, неа 0.8, ок 0.8, хз 0.4, наверное 0.4, просто 0.4, бы 0.4.

Частые слова: вечером, еще, скину, видел, только, конечно, немного, го, после, завтра, был, устал, жив, работа, завалила, выходных, отпишусь, спойлери, освобожусь, минут.
