# Факты: work

Посчитано скриптом по 118 сообщениям (56 реплик) в 1 чатах. Файл перезаписывается при сборке, свои правки вносить в guide.md. «Обычно» здесь медиана, «редко больше» это 90-й процентиль.

## Жесткие правила (их проверяет lint)

- Буква йо (е с точками): нельзя (в корпусе 0 из 2 слов, где она бывает)
- Тире (длинное, короткое, дефис с пробелами): нельзя
- Эмодзи: нельзя
- Мат: только если собеседник сам матерится

## Как выглядит реплика

Реплика это все сообщения владельца подряд, пока не ответит собеседник.

- Длина реплики: обычно 5 слов, редко больше 8.
- Сообщений в реплике: обычно 2, редко больше 3. Мысль разбита на несколько сообщений в 96% реплик.
- Одно сообщение: обычно 2 слова, редко больше 4.
- Запятые: 0 на 100 слов. В реплике от 5 слов редко больше 0 на 100 слов, в реплике целиком обычно 0, редко больше 0.
- С заглавной буквы начинается 0% сообщений.
- Конец сообщения: без знака 100%, точка 0%, вопрос 0%, скобка 0%, многоточие 0%, восклицание 0%, эмодзи 0%.
- Скобки-смайлы вроде «))» в 0% сообщений.
- Эмодзи в 0% сообщений.
- Мат в 0% сообщений.

## Словечки

Частицы и слова-паразиты, на 100 слов: щас 1.3, вроде 0.3, норм 0.3.

Частые слова: гляну, ссылку, после, без, кинь, видел, добавлю, только, вечера, таймауту, индекса, created, минут, стейдж, лежит, поднимаю, ключи, ttl, завел, задачу.
